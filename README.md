# RushUp Esports - Landing Website

A modern, high-converting, mobile-first landing website built for **RushUp Esports** (an APK-based Free Fire tournament platform in India).

![RushUp Hero Preview](images/hero_phone_mockup.png)

## 🚀 Features

- **Dark Purple Neon Theme**: Custom glassmorphism design system (`#09090B` background, `#7C3AED` primary purple, `#A855F7` accent).
- **100% Vanilla Tech Stack**: Pure HTML5, CSS3, and JavaScript without external frameworks for maximum performance.
- **Interactive UI & Micro-animations**:
  - HTML5 Canvas background particle system with glowing purple connections.
  - Smooth scroll progress indicator bar.
  - Animated live counters for Active Players, Matches Hosted, and Cash Distributed.
  - Interactive phone mockup carousel for app previews (Tournaments, Wallet).
  - Smooth expandable FAQ Accordion.
  - Click ripple button animations & floating glowing badges.
- **Full SEO & PWA Setup**:
  - Open Graph tags & Twitter Card meta data.
  - Schema.org `SoftwareApplication` JSON-LD structured data.
  - `robots.txt`, `sitemap.xml`, and `manifest.json`.
- **5 Complete Pages**:
  - `index.html` (12 detailed home sections)
  - `privacy.html` (Google Play / AdMob policy compliant privacy policy)
  - `terms.html` (Tournament fair play regulations and terms of service)
  - `contact.html` (Glassmorphic contact form & 24/7 support channels)
  - `404.html` (Custom error page with red zone gaming theme)

Because this is a pure Vanilla Web project, you can preview the website by simply opening `index.html` in any browser, or using a lightweight HTTP server (e.g. `npx http-server ./` or VS Code Live Server).
